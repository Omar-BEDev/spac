## Overview 
Given the widespread use of ai, it was essential to have this document containing rules to prevent any problems arising from it.

## Rules
1 - Adhere to the same rules in the file `CONTRIBUTING.md`<br>
2 - The pull request template must be followed when making it. <br>
3 - Add a comment indicating that this code was written by artificial intelligence, along with comments on any decisions it makes.<br>
4 - The latest version of the go language libraries must be used. <br>
5 - The branch designated for submitting pull requests is `dev`the one where any withdrawal request for another branch will be rejected.<br>
